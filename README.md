## 🌟 Overview

**ApplexDrop** bridges decentralized meme-coin speculation with real-world fiat liquidity. Whenever a coin is launched on ApplexDrop, creator fees generated from trading volume don't stay trapped on-chain — they are automatically routed and dropped directly into any recipient's **Apple Pay / Apple Cash** balance via their phone number or email address.

---

## 🚀 Key Features

* **⚡ Hey Siri, Launch a Coin**: Instant 1-click token deployment on Solana paired with Pump.fun liquidity curves.
* **📲 Direct-to-Apple Cash Routing**: Specify any recipient's phone number or email; all creator trading fees land straight into their Apple Cash card.
* **🔍 On-Chain Explorer & Leaderboard**: Track top tokens, top Apple Pay fee recipients, recent payments, and volume analytics in real-time.
* **🛡️ Non-Custodial & Permissionless**: Connect via Phantom, Solflare, or any Solana wallet. No custodial intermediaries holding your funds.
* **🎁 Gift & Share Modes**: Create tokens as tipping or donation vehicles for friends, influencers, or content creators.

## 🛠️ Local Development & Deployment

### Run Locally

```bash
# Clone the repository
git clone https://github.com/WerelayAgent/applexdrop.git
cd applexdrop

# Install dependencies and start local static server
npx serve -s . -l 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Deploy to Vercel

```bash
vercel --prod
```

Pre-configured with [vercel.json](file:///vercel.json) rewrite rules for SPA client-side routing.
